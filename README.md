# Currency Parser 💱

Скрипт для получения актуальных курсов валют с ЦБ РФ и выгрузки в Excel.

## Возможности

- Получение курсов 54 валют с официального API ЦБ РФ
- Учёт номинала (AMD, BDT и др. - за 100/1000 единиц)
- Расчёт изменения курса в рублях и процентах
- Красивое оформление Excel: жирные заголовки, цвет для роста/падения
- Автоширина колонок

## Стек

- Python 3.13
- requests - запросы к API
- pandas - обработка данных
- openpyxl - оформление Excel
